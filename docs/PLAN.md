# Stage plan

One stage is one branch. Tick a stage (`[x]`) in the same branch that finishes it.
Done lines move to `docs/PLAN-done.md` at each retro. Ticket numbers count across both files: a new ticket takes the next number after the highest in either.
Each stage's red and green tests and the open questions are in the full plan:
https://claude.ai/artifact/JSzNYRpwZJyywztJtBSk2P

How a stage is built, reviewed and merged: the `stage` skill and the hardware safety rules in `CLAUDE.md`.
Every stage is reviewed before merge by subagents (`.claude/agents/`): both the `informed-reviewer` and the `fresh-reviewer` when it can change what is sent to the laptop, the `informed-reviewer` alone when it can't ("Review tiers" in `CLAUDE.md`).
Checks only a person can do on the laptop wait in "Still to check on the laptop" below until the user confirms them.

## Still to check on the laptop
Do these in one go, on AC, with "Start with Windows" on and Num Lock off. First note your preset, keyboard colour, lid logo and native mode; the last step puts them back.

1. **Read-only config (57).** Make `%APPDATA%\blade-lite\config.toml` read-only. Press the power-mode key. The popup and the Performance mode row show the new mode, and the window shows `sent, but not saved`. Make the file writable again.
2. **Config save (61).** Change the preset in the app. `config.toml` has the new preset, and no `config.toml.tmp` is left in that folder.
3. **Sleep, then hibernate.** Set a keyboard colour that is not white. Sleep the laptop and wake it. About 2 s after wake the colour is back (the 2 s wait after wake). Press Fn + numpad Enter: the preset steps (the ticket 45 test sent only Fn, `04 0A`: Num Lock was on, fixed in ticket 59). Do the same with a hibernate.
4. **Restart (44, 18).** Turn the lid logo off. Pick the FHD 440 Hz native mode. Restart. The app starts with Windows, the logo stays off, and the screen starts at FHD 440 Hz.
5. **Put it back.** Set your native mode, keyboard colour, lid logo and preset back as you noted them. Restart once more for the native mode.
6. **App after ticket 70.** Start the app. Open the window and the flyout once, and click one preset. They work as before (ticket 70 changed only types in the shell code).
8. **Keys after wake (98).** In Balanced, on AC, sleep the laptop. Pull the charger while it sleeps. Wake it and at once press Fn + numpad Enter a few times. After about 5 s the app shows Balanced or Silent, never Performance. Then press it again: the preset steps and the popup shows. Plug the charger back in.
9. **Busy (55).** Nothing to do now. If the log ever shows a Busy error, check whether the command took effect.
10. **Brightness drag (68).** In the window, drag the keyboard brightness slider slowly and hold it. The percent beside it follows. The keyboard light changes only when you let go. Do the same in the flyout.
11. **Fans on battery (86).** Unplug the charger. In Balanced, run a CPU load (such as a game or a big build) for 2 minutes. When the app shows the CPU above about 65 °C, the fans show RPM (not 0) and you hear them. If they stay at 0 RPM, stop the load at once and note the CPU temperature.
12. **Custom fan, then Silent (37).** On AC, pick Custom and set the fan to about 3000 RPM. Wait 1 minute. Click Silent. Within 2 minutes the fans slow to about 1600 RPM or stop, as after Performance.
13. **Touchpad popup after a wake (49).** Sleep the laptop and wake it. No "Touchpad" popup shows. If Windows shows its own touchpad popup with the key, note whether the two together bother you.
14. **Heat warning (75).** Quit any running Blade Lite, start it with `cargo app`, and close its window. On Performance, run a long full CPU load (a big build or a game) for 5 minutes. If the CPU stays at 100 °C, a "Too hot" popup with "CPU" shows above the clock for about 10 s, once: it is easy to read and does not take the focus (typing goes on). The log has `too hot for 3 min`. In a game for 5 minutes, if the GPU stays at 89 °C, one popup with "GPU" shows; note whether it shows in a full-screen game, and whether it comes in every game session. Leave the app in the tray for an hour, over a sleep and a hibernate: the log has at most a few `read failed: CPU temperature` lines.

15. **Wrong file and Reset (77).** Export and Import were checked by the user 2026-11-10. Start the app with `cargo app`. Click Import… and pick a file that is not settings (such as any `.txt`): an error shows and nothing changes. Click Reset: Balanced, white keys at full light, lid logo on. Then Import your own file to put your settings back.

16. **Keys after a quiet spell (131).** Start the app with `cargo app`. Touch no key for 3 minutes. Then press Fn + numpad Enter once (Num Lock on) or the power-mode key. The preset steps on the first press. Do it 3 times.
17. **Controller switched off and on (132).** Start the app with `cargo app`. In Device Manager, under Human Interface Devices, find the Razer controller (VID 1532, PID 02C7), disable it, wait 10 s, then enable it. Within about 10 s the log has `the controller was opened again`, and about 2 s later your keyboard colour and preset are sent again. Then click a preset: it works. If you can't find the device, skip this.
18. **Quit sends Balanced (130).** On AC, start the app with `cargo app`. Pick Custom and set the fan to 3500 RPM. Wait 1 minute. Quit from the tray. Do this at idle (no load). Within 2 minutes the fans drop to about 1600 RPM or stop, as auto does at idle, and never stay near 3500 (Balanced, fans on auto). Then start the app, pick Custom at 3500 RPM again on AC, wait 1 minute, and pull the charger (the app sends Balanced alone): within 2 minutes at idle the fans drop the same way. Plug it back in.
