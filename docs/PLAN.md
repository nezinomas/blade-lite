# Stage plan

One stage is one branch. Tick a stage (`[x]`) in the same branch that finishes it.
Done lines move to `docs/PLAN-done.md` at each retro. Ticket numbers count across both files: a new ticket takes the next number after the highest in either.
Each stage's red and green tests and the open questions are in the full plan:
https://claude.ai/artifact/JSzNYRpwZJyywztJtBSk2P

How a stage is built, reviewed and merged: the `stage` skill and the hardware safety rules in `CLAUDE.md`.
Every stage is reviewed before merge by subagents (`.claude/agents/`): both the `informed-reviewer` and the `fresh-reviewer` when it can change what is sent to the laptop, the `informed-reviewer` alone when it can't ("Review tiers" in `CLAUDE.md`).
Checks only a person can do on the laptop wait in "Still to check on the laptop" below until the user confirms them.

- [ ] 148 Install, upgrade and uninstall must leave the fans on auto (adds to 39 and 78). If no copy runs at uninstall, a crash may have left a manual fan: send Custom with the fans on auto, then Balanced, once (such as `--reset`). Both reviewers
- [ ] 149 Security of the release build (adds to 39 and 40). No release workflow yet. Build the release in CI from a tag, with `--locked` and actions pinned by commit, and publish SHA-256 sums beside the files. `Cargo.toml` has no `[profile.release]`: decide the panic mode (with ticket 141), overflow checks and symbols. CI files: `informed-reviewer`; the NVML path: both reviewers

## Still to check on the laptop
Do these in one go, on AC, with "Start with Windows" on and Num Lock off. First note your preset, keyboard colour, lid logo and native mode; the last step puts them back.

1. **Read-only config (57).** Make `%APPDATA%\blade-lite\config.toml` read-only. Press the power-mode key. The popup and the Performance mode row show the new mode, and the window shows `sent, but not saved`. Make the file writable again.
2. **Config save (61).** Change the preset in the app. `config.toml` has the new preset, and no `config.toml.tmp` is left in that folder.
3. **Sleep, then hibernate.** Set a keyboard colour that is not white. Sleep the laptop and wake it. About 2 s after wake the colour is back (the 2 s wait after wake). Press Fn + numpad Enter: the preset steps (the ticket 45 test sent only Fn, `04 0A`: Num Lock was on, fixed in ticket 59). Do the same with a hibernate.
4. **Restart (44, 18).** First start the app with `powershell -ExecutionPolicy Bypass -File tools\Start-CheckApp.ps1` and tick "Start with Windows" in its tray menu: it saves the running exe's path, and on 2026-11-12 the Run key had no Blade Lite value. Turn the lid logo off. Pick the FHD 440 Hz native mode. Restart. The app starts with Windows, the logo stays off, and the screen starts at FHD 440 Hz.
5. **Put it back.** Set your native mode, keyboard colour, lid logo and preset back as you noted them. Restart once more for the native mode. "Start with Windows" now starts the check build in `target\app\release` of that checkout; tick it again from the copy you want at login.
6. **App after ticket 70.** Start the app. Open the window and the flyout once, and click one preset. They work as before (ticket 70 changed only types in the shell code).
8. **Keys after wake (98).** In Balanced, on AC, sleep the laptop. Pull the charger while it sleeps. Wake it and at once press Fn + numpad Enter a few times. After about 5 s the app shows Balanced or Silent, never Performance. Then press it again: the preset steps and the popup shows. Plug the charger back in.
9. **Busy (55).** Nothing to do now. If the log ever shows a Busy error, check whether the command took effect.
10. **Brightness drag (68).** In the window, drag the keyboard brightness slider slowly and hold it. The percent beside it follows. The keyboard light changes only when you let go. Do the same in the flyout.
11. **Fans on battery (86).** Unplug the charger. In Balanced, run a CPU load (such as a game or a big build) for 2 minutes. When the app shows the CPU above about 65 °C, the fans show RPM (not 0) and you hear them. If they stay at 0 RPM, stop the load at once and note the CPU temperature.
12. **Custom fan, then Silent (37).** On AC, pick Custom and set the fan to about 3000 RPM. Wait 1 minute. Click Silent. Within 2 minutes the fans slow to about 1600 RPM or stop, as after Performance.
13. **Touchpad popup after a wake (49).** Sleep the laptop and wake it. No "Touchpad" popup shows. If Windows shows its own touchpad popup with the key, note whether the two together bother you.
14. **Heat warning (75).** Quit any running Blade Lite, start it with `cargo app`, and close its window. On Performance, run a long full CPU load (a big build or a game) for 5 minutes. If the CPU stays at 100 °C, a "Too hot" popup with "CPU" shows above the clock for about 10 s, once: it is easy to read and does not take the focus (typing goes on). The log has `too hot for 3 min`. In a game for 5 minutes, if the GPU stays at 89 °C, one popup with "GPU" shows; note whether it shows in a full-screen game, and whether it comes in every game session. Leave the app in the tray for an hour, over a sleep and a hibernate: the log has at most a few `read failed: CPU temperature` lines.

15. **Wrong file and Reset (77).** Export and Import were checked by the user 2026-11-10. Start the app with `cargo app`. Click Import… and pick a file that is not settings (such as any `.txt`): an error shows and nothing changes. Click Reset: Balanced, white keys at full light, lid logo on. Then Import your own file to put your settings back.

16. **Keys after a quiet spell (131).** Start the app with `cargo app`. Touch no key for 3 minutes. Then press Fn + numpad Enter once (Num Lock on) or the power-mode key. The preset steps on the first press. Do it 3 times. Tries 1 (2026-11-11) and 2 (2026-11-12, Fn + numpad Enter, Num Lock on) passed (user). Try 3 (2026-11-12, Num Lock off, numpad Enter alone) stepped only on the second press: ticket 158. After 158, do one more try with Num Lock off.
19. **Fan guard, GPU part (129).** Part A (CPU) passed 2026-11-11. On AC, start the app with `cargo app` and open the window. Pick Custom, CPU and GPU boost at the top, fan 1600 RPM. Play a game for 5 minutes with the CPU under 95 °C: if the GPU stays at 87 °C or more, a "Fans" popup says "Full speed" and the fans read about 4500 RPM. The fans go back only once the GPU is under 77 °C (or at once if it sleeps; a GPU whose reads fail keeps the fans at full speed, tickets 139 and 156). Note whether the log has `read failed: GPU` and whether the popup shows over the game. Then set your preset back.

Checks from the audit of 2026-11-11 (tickets 141 to 153). They need no new code. Do 22 at idle, on AC.

22. **Sleep with a manual fan (142).** Start the app with `cargo app`, pick Custom and set the fan to 3500 RPM. Sleep the laptop from the Start menu and listen for 2 minutes: note whether the fans stop. Wake it: about 5 s later the fans are near 3500 again. Do the same with a closed lid, and with a hibernate. Then set your preset back.
25. **Beside HWiNFO and Afterburner (145).** Only if you use them. Start the app with `cargo app` and open the window. Run HWiNFO (sensors window open) for 30 minutes, and click each preset once in that time. No Razer warning shows in the window. The log has no new line with `the reply is for another request`, `stayed busy` or `the HID layer failed`. Do the same with MSI Afterburner. Razer Synapse is not installed, so it is not checked; do not install it for this.
26. **One day in the tray (147).** In the checkout's root, quit any running Blade Lite and start the app with `powershell -ExecutionPolicy Bypass -File tools\Start-CheckApp.ps1` (a restart or shutdown in the day would kill a `cargo app` run, ticket 166), and close its window. In another PowerShell in the same folder run `powershell -ExecutionPolicy Bypass -File tools\Watch-BladeLite.ps1 -Minutes 1440 -Out target\soak.csv` and leave it running (don't open the CSV in Excel while it runs; copy it first). Use the laptop as usual for 24 hours, with a sleep or a hibernate and a charger pull in that time. Then send `target\soak.csv` and the log to Claude: memory (`private_mb` is the one for the 15 MB target), handles and threads should stay about the same; count the log lines with `failed`, `stayed busy` or `another request`.
27. **A hot manual fan with no app (141, 150).** Do this last, and only with HWiNFO or another tool that shows the CPU temperature. On AC, start the app with `cargo app`, pick Custom, CPU and GPU boost at the top, fan 1600 RPM. End `blade-lite.exe` in Task Manager. Run a full CPU load for 2 minutes at most. Note the CPU temperature and whether the fans speed up by themselves. Stop the load at once if the CPU stays at 100 °C for 30 s with the fans still slow. Then stop the load, start the app and pick Balanced at once (the start sends the saved Custom with 1600 RPM again). Set your own preset back when the laptop is cool.
28. **Monitor plugged in and out on battery (hot-plug).** With "Switch to 60 Hz on battery" on, pull the charger: the laptop's screen goes to 60 Hz. Unplug the external monitor, wait 10 s, plug it in again. The laptop's screen stays at 60 Hz and the window shows no error. Plug the charger in: the old rate comes back.
29. **Fan target after a cold boot (144).** Turn off "Start with Windows" for this one, or note your preset first. Shut the laptop down (not restart), wait 1 minute, start it, and do not start Blade Lite. Run `cargo test -p razer-device --test hardware -- --ignored --nocapture a_custom_mode_write_alone`. Note the `before` line's last two entries (the fan targets, such as `[01, 01, 14]` = 2000 RPM). If the test refuses with "outside the model's range", that target would stop or slow the fans after a cut Custom send: tell Claude. Turn "Start with Windows" back on.
30. **Restart right after a wake (137, 166).** Quit any running Blade Lite. Start the app with `powershell -ExecutionPolicy Bypass -File tools\Start-CheckApp.ps1` (not `cargo app`, ticket 166), pick Custom and set the fan to 3500 RPM. Hibernate, wake the laptop, and within 1 s of the desktop pick Restart. After the restart, look in the log: it has `the quit waits ... ms for the controller to be ready` and no `Balanced was not sent`; before you sign in, the fans are back to normal (with "Start with Windows" on, the login start sends Custom 3500 again). Then set your preset back.
31. **Login start without the controller (153).** Quit Blade Lite. In Device Manager (admin), disable the Razer controller (Human Interface Devices, the one with `VID_1532&PID_02C7&MI_00` in its hardware IDs). Run `cargo app -- --tray`. After about 10 s a box says the app tries again every 30 s. Enable the device again. Within 30 s the tray icon shows, and the log has `still trying` or the open, then `starts`. Close the box.
