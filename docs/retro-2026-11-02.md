## 1. Permissions block the agent at random (Information access / Tool economy)

**What happened**
- Stage 0: the safety check blocked `cargo build`, even after you said "build it". Then the build ran later anyway.
- Stage 2: "I am not allowed to push to master". You had to run `git push origin master`.
- Stage 3: the agent pushed master itself. No block.
- Stage 4: branch delete blocked. You got 2 commands to run.
- Stage 5: branch delete worked.
- Stage 2: merging PR #1 was denied.

The same command was blocked in one thread and allowed in the next. You became the hands for the agent many times.

**Fix:** add allow rules to `.claude/settings.json` for the commands your git rules need:
`cargo build`, `cargo test`, `cargo fmt`, `cargo clippy`, `git merge --no-ff`, `git push origin master`, `git push origin --delete`.
The file already allows `git push:*` and `git branch:*`, but the blocks still came. So check with `/permissions` in a terminal `claude` which rule wins.

## 2. CI never sees a branch before it is merged (Automated checks)

**What happened:** the git rule is "no PR, merge locally, then push". `ci.yml` runs only on push to `master` and on PRs. So CI checks the code only after it is already on master. There is no pre-commit or pre-push hook.

**Fix (pick one):**
- A `pre-push` hook (in a committed `.githooks/` folder) that runs `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`.
- Or add `branches: ['**']` to the `push` trigger in `ci.yml`, and push the branch before the merge.

## 3. The Python capture tests exist but nothing runs them (Automated checks)

**What happened:** stage 1 had 3 script bugs. You found each one by running the script: USBPcap names not read, old recorders lock files, Process Monitor not found. `capture/test_decode_usbpcap.py` exists, but CI does not run it.

**Fix:** add one CI step: `python -m unittest discover capture`. The PowerShell script has no tests. That is OK if the capture is done for good.

## 4. "No AI attribution" is a rule, not a check (Coding standards, mechanical)

**What happened:** history is clean now. But the tool itself tells the agent to add `Co-Authored-By` lines. Only memory stops it.

**Fix:** a `commit-msg` hook that rejects messages with `Co-Authored-By` or `claude.ai`. A rule in a file can slip. A hook can not.
